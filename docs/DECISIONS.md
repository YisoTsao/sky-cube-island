# 實作決策紀錄（DECISIONS）

本文件記錄實作 v2.1 GDD／技術架構時，文件未明確規定或刻意偏離之處。

| # | 決策 | 理由 |
|---|------|------|
| D-01 | 不使用 R3F，改用 `SceneApp` 類別管理的純命令式 Three.js | 每幀數百實體與後處理管線，用命令式較好控制 draw call 與 GC；React 只負責低頻 HUD（符合 Tech §8.2 精神）。 |
| D-02 | 新增 `CONTINUE` 指令（WAVE_RESULT → PREPARE） | 文件有結算畫面但未定義離開的指令；維持「所有狀態轉移都是指令」。 |
| D-03 | 新增拒絕碼 `MAX_LEVEL` | 升級已滿級塔需要明確回饋。 |
| D-04 | `GameState` 新增 `builtWave`、`spawnQueue`、`frozenRoutes` | 分別用於統計、確定性出怪、戰鬥中凍結路線（存檔可完整還原）。 |
| D-05 | 視線（LOS）只看地形柱頂，木牆與橋面不遮擋 | 讓牆的用途單純是「改路」，避免玩家誤以為擋視線；Amanatides–Woo 2D 精確格走訪。 |
| D-06 | 核心周圍一圈為保護區 | 避免把塔直接堆在核心旁或封死最後一段路。 |
| D-07 | 太陽方向為畫面左上偏向鏡頭 | 等角視角下島嶼側面有明暗對比、陰影落在右後方不遮擋路線。 |
| D-08 | 開場運鏡用正交鏡頭環繞＋移軸（tilt-shift），不切透視鏡頭 | 與遊戲視角一致、沒有切換跳動，移軸提供「模型島」質感。 |
| D-09 | 調色以自製 GradeEffect 取代 LUT 檔 | 不需外部資產，參數可依畫質調整。 |
| D-10 | 音效、音樂全部 Web Audio 程序合成（已由 D-19 部分取代） | 零授權風險、零下載；每次播放 ±5% 音高、±2 dB 變化避免重複感。 |
| D-11 | 可改造地塊的符文格線依情境顯示（戰鬥 0、待機 0.3、拿地形工具時 1） | 常駐全亮會讓畫面很雜，玩家需要時才強調。 |
| D-12 | 數值平衡維持文件原值 | 自動測試的貪婪機器人能無漏怪通關 5 波，代表偏簡單；待實際試玩後再調整。 |
| D-13 | 低畫質使用 BasicShadowMap，其他使用 PCF（three r18x 已移除 PCFSoft） | 相容新版 three。 |
| D-14 | N8AO 一律全解析度（「高」用 8 取樣、「極致」16 取樣） | n8ao 2.0.1 的半解析度路徑使用 MRT render target，與 three r18x 不相容會丟錯；改以降低取樣數控制成本。 |
| D-15 | 取代 D-12：L1-01 改為長波次、多怪物（v2.2） | 試玩回饋「太簡單、太短」。每波出怪至少持續 120 秒（兩個入口都是），每波 90–200 隻，並新增 `WaveDef.hpScale`（1.0 → 1.8）讓後段更硬。由 `tests/integration/balance-bot.test.ts` 的機器人鎖住：積極再投資的機器人能贏但會掉血，只在準備期花錢或留著金幣不用的機器人會輸。 |
| D-16 | 新增 5 種怪物：小果凍、分裂史萊姆、鐵甲甲蟲、癒光精靈、岩王巨像 | 大量怪物需要不同解法：成群（砲塔）、分裂（持續火力）、物抗 50%（冰晶塔魔法）、治療光環（優先擊倒）、Boss（緩速減半）。治療量為固定值 × hpScale，避免以百分比治療 Boss 造成無法擊殺。 |
| D-17 | 戰鬥中可建塔、升級、出售（地形與木牆仍限準備期） | 兩分鐘以上的波次若只能在波次之間花錢，擊殺金幣會閒置。戰鬥中新塔不可蓋在已凍結的敵人路線上（拒絕碼 `ON_ACTIVE_ROUTE`），並照常檢查下一波仍有路可走。 |
| D-18 | 冰晶塔基礎傷害 8 → 16、起始金幣 220 → 300，擊殺金幣下調 | 冰晶塔成為對付鐵甲甲蟲的魔法主力；大量怪物時以數量帶來收入，單隻獎勵降低以免經濟失控。 |
| D-19 | 取代 D-10：背景音樂與主要音效改用 CC0 錄音素材（cynicmusic、Kenney、Beatscribe） | 試玩回饋希望音樂更好聽。只採用 CC0 素材，來源逐一登記於 `public/audio/CREDITS.md`。素材在第一次點擊後才延遲載入（約 3 MB），載入前或失敗時自動退回原本的程序合成，因此離線開啟 dist/ 仍有聲音。核心 HP ≤4 的緊張層改為戰鬥曲加速 7%。 |
| D-20 | 新增雷光塔（GDD §16 T2「雷光塔（連鎖）」）：115 金、魔法 24、射程 3.0、1.7 秒；命中後跳到 1.7 格內最近且未被打過的敵人，Lv1/2/3 跳 2/3/4 次，每跳傷害 ×0.75 | 大量小怪的關卡需要第二種群體解法，與砲塔（物理、落點爆炸）互補：雷光是魔法、沿著隊伍延伸。跳躍不檢查視線，只有第一下需要 LOS。 |
| D-21 | 新增風車塔（GDD §16 T2「風車塔（推退）」）：95 金、物理 8、射程 2.6、2.8 秒；一次吹中射程內最多 4/5/6 隻，沿原路線往回推 0.9/1.2/1.5 格，被推後 3.5 秒內免疫再推 | 推退只沿凍結路線往回移動，不改路、不穿崖，符合「戰鬥中路線固定」。免疫時間避免無限卡怪；頭目與重甲有 `knockbackResistance`（30–80%）。 |
| D-22 | 索敵模式 FIRST／LAST／STRONGEST／CLOSEST，新指令 `SET_TARGETING`（準備期與戰鬥中皆可，免費） | GDD §16 T2「索敵模式」。同分時一律退回 FIRST、再依出生順序，維持確定性；存檔 schema 接受舊檔的 FIRST。快捷鍵 T 循環切換選取的塔。 |
| D-23 | 每關 3 個可選挑戰＋本機最佳紀錄（GDD §16 T1）。挑戰只讀 `GameState.run`（由成功指令累計，撤銷會一起還原，存檔會帶著）與通關時的核心生命，不改任何規則；紀錄存在 `skybound.progress.v1` 的 `records`（最佳剩餘生命、通關次數、完成過的挑戰聯集），舊進度檔照常讀取 | 給已通關的玩家重玩的理由。挑戰清單放在 `src/domain/challenges.ts`，不改 LevelDef schema；選單顯示這局的即時狀態，勝利畫面顯示結果，關卡卡片顯示累積進度。 |
| D-24 | 環境生命感（GDD §16 T1）：鳥群、瀑布（熔岩關為熔岩瀑布、雪關為淡藍水）、飄落物（花瓣／楓葉／雪花／上升火星）放在 `src/scene/environment/ambient-life.ts`，只讀關卡靜態資料 | 純表現層：不投影、不寫入深度圖層，所以不遮戰術線也不影響點選。瀑布挑「外側是虛空、兩側同高」的平台邊緣格，避開入口／核心／橋端保護區，彼此至少相隔 7 格。低畫質只有一群鳥、沒有飄落物；「減少動態」時數量減半、速度放慢。 |
| D-25 | 拍照模式（GDD §12 P 鍵，T1）：隱藏 HUD、暫停戰鬥、自由鏡頭（任意角度、俯角 18°–80°、縮放範圍放寬）、6 種濾鏡、移軸、隱藏戰術線、截圖 | 不發出任何指令；離開時把鏡頭與暫停狀態還原。移軸是常駐在後處理鏈中的獨立 pass，強度 0 時直接回傳原色——避免可切換 pass 放在鏈尾造成黑畫面（見 pipeline 註解）。濾鏡在 GradeEffect 內，戰術層在後處理之後繪製，遊戲中濾鏡固定為 0。截圖在同一個工作階段內先重繪再 `toDataURL`，不需要 `preserveDrawingBuffer`；觸控裝置優先用系統分享。 |
| D-26 | 無盡模式（GDD §16 T3）：每關通關後解鎖 `L1-0X-E`，是一份普通 LevelDef（同地圖、99 波生成波次），引擎、存檔、撤銷都不用特例 | 波次由 `src/levels/endless.ts` 確定性產生：怪物池取該關出現過的非頭目怪、由弱到強逐波加入；第 n 波生命倍率 `min(首波,0.6)×(1+0.09n)×1.03ⁿ`；每 5 波加入該關頭目；清波金 90+12n（上限 260）。紀錄以「撐過幾波」計，每次清波就寫入 `progress.endless`（舊進度檔照常讀）。LevelDef 的 `hpScale` 上限從 10 放寬到 1000。`tests/integration/balance-endless.test.ts` 鎖住難度：戰役能贏的機器人在四關無盡模式都會在第 8～45 波之間落敗（目前約 12～16 波）。 |
| D-27 | 飛行怪「風翼飛龍」（GDD §16 T2）：生命 130、速度 0.75、漏怪扣 1；出生時路徑只有兩點（入口 → 最近的核心接近點），沿直線飛越虛空、懸崖、木牆與陷阱，飛行高度 1.7 | 沿用引擎的「路徑節點＋段落進度」模型：段長用 `flightDist` 正規化移動與推退距離，所以存檔、撤銷、推退都不需特例。只有塔能打飛龍（瞄準點加上飛行高度，視線照常檢查）；陷阱不觸發。 |
| D-28 | 拆路障怪「破牆角獸」：生命 280、物抗 25%；出生時以「沒有木牆」計算路線，走到木牆前一格停下，3 秒後撞碎木牆（事件 `WALL_DESTROYED`）再繼續 | 木牆是玩家改路的主要手段，角獸逼玩家用地形或塔來改路。戰鬥中新塔不可蓋在任何活著敵人的路徑上，避免角獸被新塔卡住。沒有木牆時角獸走一般路線。 |
| D-29 | 陷阱（GDD §16 T2）：40 金、拆除退 20；只能放在一般地面（非水、非橋、非入口／核心／接近點），不擋路；每 1 秒對站在該格的地面敵人造成 34 點物理傷害（隨波次血量倍率 √hpScale 成長） | 給玩家「路上」的火力選項而不影響路線驗證。鑽地中的地鼠與飛行怪不受影響。新指令 `PLACE_TRAP`／`REMOVE_TRAP`，快捷鍵 J；點選有陷阱的地塊可拆除。 |

| D-35 | 關卡編輯器與分享（GDD §16 T3）：自訂關卡＝浮島產生器描述檔＋逐格修改（`overrides`：抬高、石柱、挖空、補地），以 base64url JSON 放進 `?custom=` 網址分享，不需要伺服器；關卡 id 為描述檔雜湊 `C-xxxx` | 描述檔只有數百字元，比整份 LevelDef 小得多，網址可直接分享。分享資料視為不可信：先以 zod `CustomSpecSchema` 嚴格解析（版本、已知怪物種類、數值上下限、最多 600 格修改、分享碼最長 12000 字），再經產生器與同一套關卡驗證器，任何一步失敗就不讓遊玩並顯示原因。編輯器固定使用單一種子（不自動重試），修改才會留在塗抹的位置；🎲 隨機與預設值只挑沒有修改時能通過驗證的種子。「我的關卡」存在本機 `skybound.custom.v1`（最多 30 個）。 |
